# Community skills

Open-source skills about workflow automation, agentic workflows, integrations and iPaaS, published by other people and copied here unchanged under their own licenses. Each folder is one source repository and has:

- `SOURCE.md`: the author, the original repository, the commit copied, and the license.
- `LICENSE`: the original license text.
- The Markdown of the skill folders only. Scripts, assets and other files stay in the original repository.

Relative links to files that were not copied point to the original repository at the copied commit, and those files say so at the end.

**Not reviewed yet.** These skills have not been checked against this library's rules (vendor neutrality, safety gates, no secrets). They live outside `skills/`, so the validator and the site do not treat them as library skills. Read a skill and its source before you install it.

Selection (2026-11-24): skills by people found in public research on automation creators and practitioners, from public repositories with an open license (MIT, Apache-2.0, BSD, CC-BY-4.0, Unlicense, 0BSD), kept only when their main purpose is automation or integration.
