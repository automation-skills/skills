## Contributing Reference Documentation

We welcome contributions to fill out these reference documents! Please see [CONTRIBUTING.md](../CONTRIBUTING.md) for guidelines.

### Reference File Template

When creating or enhancing reference files, use this structure:

```markdown
# [Topic Name]

**Last Updated:** [Date]
**Applies to:** Power Automate [Cloud/Desktop/Both]

## Overview

Brief description of the topic and why it matters.

## Key Concepts

### Concept 1
Explanation with examples

## Common Patterns

### Pattern 1: [Pattern Name]
Description, use case, implementation

## Best Practices

- Practice 1 with explanation
- Practice 2 with explanation

## Common Pitfalls

### Pitfall 1
Problem, why it happens, solution

## Examples

### Example 1: [Scenario Name]
Step-by-step example with code/flow definition

## Additional Resources

- [Official Microsoft Docs](URL)
- [Related Reference Files](PATH)
```

Power Automate evolves rapidly. To keep references current:

- Check Microsoft Learn documentation quarterly
- Update when new major features are released
- Add notes about deprecated features
- Include version-specific guidance where relevant
- Link to official Microsoft documentation
